## What Is CODESOFT

CODESOFT is TEKLYNX barcode label software for Windows. You design a label, attach data from a list you already keep, and send it through CODESOFT native drivers to a thermal printer you run. That driver path is a large part of why plants pick CODESOFT barcode printers: the job is not filtered through a slow generic spooler if the head already understands the TEKLYNX stream.

People look for CODESOFT TEKLYNX labels when they have outgrown a simple sticker editor but are not looking for a full MES. A packing desk, a spare-parts counter, or a small plant on a PC they own can keep formats for the printers in that room. CODESOFT RFID labels are optional: use them when the tags on the shelf are yours to write, and skip them when the job is barcode only.

CODESOFT is not a photo editor and not a mail-merge wizard for wedding invites. It is a local barcode platform for labels you are authorized to print. Keep each line's formats together, and leave other companies' artwork out of that folder.

## Starting with CODESOFT

Prerequisites: A PC you own, a TEKLYNX-supported printer you already run, and item data you are allowed to print.

1. **Prepare:** Install the printer as the line uses it, then open CODESOFT TEKLYNX labels on a format for that head.
2. **Configure:** Select CODESOFT native drivers for the model on the bench and set the canvas to the roll in the box.
3. **Test:** Print one barcode from CODESOFT barcode printers and scan it with a reader you already keep.
4. **Refine:** If the line uses chips you own, encode one sample with CODESOFT RFID labels and confirm the reader sees it.
5. **Apply:** Print the batch for stock you already pack, changing only serials or lots that belong to this run.
6. **Maintain:** Store formats next to that printer's notes, and keep other sites' labels out of this copy of CODESOFT.
7. **Scan again:** After a ribbon change, print one code and scan it before the rest of the batch.
8. **Roll width:** Confirm the canvas still matches the new roll if the box size changed.
9. **RFID skip:** Leave CODESOFT RFID labels off the job when the line is barcode only.
10. **Head swap:** If the printer model changes, reselect CODESOFT native drivers before a long run.
11. **Ribbon:** After a ribbon change, reprint one sample before the rest of the roll.
